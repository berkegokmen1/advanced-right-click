# Changelog

## 0.1.4

- Compact video and audio previews for trimming, with playback, a visual timeline, adjustable start/end handles and editable timecodes.
- GIF range preview with selected-segment playback and a 15-second selection limit.
- Audio waveform preview.
- PDF page previews and thumbnails for PDF creation, merging, extraction, splitting, rotation, compression and searchable PDFs.
- Visual PDF range selection using Set start / Set end.
- Popup windows fit their contents at 380px wide; closing a media popup stops playback.

## 0.1.3

- Fixed Finder commands silently failing after Finder discarded menu item metadata.
- Menus adapt to file type, single or multiple selections, mixed selections and folder backgrounds.
- In-place edits preserve Finder file references.
- Fixed PDF compression and repeated generated-output naming.
- Added audio trimming and expanded coverage to all 38 actions.

## 0.1.1

- Colored native action icons and distinct format badges.
- Shared grouped Finder and Services menus.

## 0.1.0

- Initial native macOS utility with Finder actions, compact configuration and recoverable file changes.
